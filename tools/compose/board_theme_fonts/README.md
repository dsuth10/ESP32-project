# Teaching Board bundled fonts

These files are loaded only from this folder. The application never fetches
fonts from the network.

| Family | Files | Licence |
| --- | --- | --- |
| Inter | `Inter-*.ttf` | SIL Open Font License 1.1 (`OFL-Inter.txt`) |
| JetBrains Mono | `JetBrainsMono-*.ttf` | Apache License 2.0 (`Apache-2.0-JetBrainsMono.txt`) |

If a file cannot be registered on this computer, the theme falls back to a
system UI font (Segoe UI, Noto Sans, Liberation Sans) and a system monospace
font. Lesson page text keeps its existing renderer font and is not restyled here.
